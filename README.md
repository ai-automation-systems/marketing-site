# Лендинг агентства — продвижение и настройка бизнеса

Статический сайт-лендинг: соцсети, автоматизация, сайты, Яндекс Директ / VK Реклама, фото и видео.
Хостится бесплатно на GitHub Pages.

## Быстрая настройка

Всё, что нужно менять на старте, лежит в одном файле — [`js/config.js`](js/config.js):

```js
const SITE_CONFIG = {
  brandName: "СТУДИЯ",                    // название — появится в шапке и подвале
  telegramUrl: "https://t.me/username",   // сюда ведут все кнопки связи
};
```

Поменяли → сохранили → закоммитили. Сайт обновится сам через 1–2 минуты.

## Структура

```
index.html        все тексты и блоки страницы
css/style.css     оформление
js/config.js      НАСТРОЙКИ: название и Telegram
js/main.js        меню, подстановка настроек, анимации
```

## Что менять дальше

- **Тексты услуг и пакетов** — прямо в `index.html`, блоки `<!-- УСЛУГИ -->` и `<!-- ПАКЕТЫ -->`.
- **Кейсы** — блок `<!-- КЕЙСЫ (заглушка) -->`. Сейчас там карточки «Скоро».
  Когда появятся реальные кейсы, заменить текст внутри `<article class="case">`
  и убрать класс `case--soon` (уберётся пунктирная рамка).

## Локальный просмотр

```
python3 -m http.server 4173
```

Открыть http://localhost:4173

## Публикация

Репозиторий → Settings → Pages → Source: `main`, папка `/ (root)`.
Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
